# Cybersecurity Assessment & Hardening Lab

A hands-on cybersecurity lab focused on network assessment, system hardening, vulnerability analysis, packet inspection, Python automation, and remediation testing.

## Project Goals

This project is designed to build practical cybersecurity experience by creating and securing a controlled virtual lab environment.

The main goals are to:

- Build and document a small virtual network environment
- Identify active hosts, services, and exposed ports
- Analyze network traffic using packet-capture tools
- Identify vulnerabilities and security misconfigurations
- Apply system and network hardening techniques
- Use Python to automate portions of the assessment process
- Verify that implemented security changes reduce identified risks
- Document findings, remediation steps, and lessons learned

## Lab Environment

The lab will use systems and networks that I own and control for educational and defensive cybersecurity practice.

Specific architecture and system configurations will be documented as the environment is built.

## Project Phases

### Phase 1 — Lab Setup
Create the virtual environment, configure networking, and document the initial architecture.

### Phase 2 — Baseline Assessment
Identify hosts, ports, services, configurations, and normal network activity.

### Phase 3 — Traffic Analysis
Capture and analyze network traffic to better understand protocols and system communication.

### Phase 4 — Vulnerability Assessment
Identify vulnerabilities, insecure configurations, and unnecessary exposure within the lab.

### Phase 5 — Hardening and Remediation
Apply security improvements based on identified findings.

### Phase 6 — Verification
Repeat assessments and compare results to determine whether the implemented changes were effective.

### Phase 7 — Automation
Develop Python or shell scripts to automate useful portions of the assessment and verification process.
